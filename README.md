# Marvin Rocha — Personal Portfolio Website

Personal portfolio of **Marvin Rocha**, Senior Fullstack Engineer, built on top of the award-winning [giats.me](https://giats.me) template by [Evangelos Giatsidis](https://github.com/Giats2498), adapted with real content, case studies, and branding.

---

## 🧠 Concept & Structure

The visual foundation is built around a **three-phase layering system**:

1. **The Background Phase** — a dynamic, animated 3D world rendered with React Three Fiber.
2. **The Main Website Phase** — projects, about section, contact, etc.
3. **The Fluid Animation Layer (Above All)** — a real-time fluid simulation overlays the interface using `mix-blend-mode` and the cursor.

---

## ⚙️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React, Pages Router)
- **3D & Canvas:** [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Animation:** [GSAP](https://greensock.com/gsap/) with ScrollTrigger
- **Styling:** SCSS / CSS Modules
- **Hosting:** [Vercel](https://vercel.com)

---

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
